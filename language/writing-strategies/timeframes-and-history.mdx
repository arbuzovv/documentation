Открытый движок работает на тех данных, которые вы ему даёте. Глубина истории, задержка и покрытие определяются вашим источником, а не движком.

## Источники данных

| Источник | Что | Как подключить |
| --- | --- | --- |
| Finam Trade API | Справочник инструментов, акции и фонды Мосбиржи, бары от минуты до квартала | Провайдер `finam` из [zipfinam](https://github.com/arbuzovv/zipFinam): `ziplime ingest-assets -p finam`, `ziplime ingest -p finam`. Нужен токен `GRPC_TOKEN` |
| MOEX AlgoPack | Биржевая аналитика по ленте сделок и стакану: `tradestats`, `orderstats`, `obstats`, `hi2`, `futoi`, `alerts` | Адреса `algopack://` из zipfinam, без загрузки — например, `data_source="algopack://eq/tradestats"`. Нужен ключ `ALGOPACK_API` с подпиской на [data.moex.com](https://data.moex.com) |
| Yahoo Finance | Справочник, дневные и внутридневные бары, срочные фьючерсы США | Встроенный провайдер `yahoo`. Российские бумаги покрывает плохо |
| Hugging Face Hub | Данные на момент публикации: фундаментальные показатели, сделки инсайдеров, сделки конгрессменов, календарь отчётностей (компании США) | Подключается во время запуска, без загрузки — см. [«Данные на момент публикации»](/language/strategy-language/point-in-time-datasets) |
| CSV | Ваши бары или собственные данные | Python API — см. `examples/run_simulation_minute_custom_csv_data.py` в репозитории Ziplime |
| Расширения | Всё, что регистрирует пакет | Точка входа `ziplime.data_providers`; `ziplime providers` показывает, что доступно в вашей установке |

<Warning>
  В истории многих источников есть ошибка выжившего: бумаг, ушедших с биржи, там нет. Стратегия, которая хорошо выглядит на сегодняшних «выживших», могла быть недоступна для торговли в то время.
</Warning>

## Бандлы

Бары загружаются в именованный **бандл**, хранятся как таблицы Delta Lake в `~/.ziplime/data` и привязаны к `sid` каждого инструмента в базе инструментов. Поэтому справочник инструментов загружается первым:

```bash
ziplime ingest-assets -p finam
ziplime ingest -p finam -c XMOS -b moex -s SBER@MISX,GAZP@MISX,LKOH@MISX \
  --start-date 2019-01-01 --end-date 2025-12-31 -f 1d
ziplime bundles
```

- `-f, --frequency` задаёт интервал баров бандла: `1m`, `5m`, `15m`, `30m`, `1h`, `1d` и другие.
- `-c, --trading-calendar` — календарь, по которому строятся сессии. Для акций Мосбиржи — `XMOS`; по умолчанию CLI использует `XNYS`.
- `--merge` добавляет данные в существующий бандл вместо замены.
- `--forward-fill` (включён по умолчанию) заполняет сессии, в которые инструмент не торговался, предыдущей ценой закрытия.
- Тикер, который не уникален, записывается как `TICKER@MIC`. Для Мосбиржи используйте `SBER@MISX`.

Каждая загрузка создаёт новую версию бандла; `ziplime run --bundle-version` выбирает нужную, а `ziplime clean` удаляет старые.

## Таймфреймы

**Частота запуска** (emission rate) — как часто вызывается `handle_data` — может быть любой от минуты до дня: 1 минута, 5, 15, час, день.

```bash
ziplime run -f strategy.py -b moex_intraday -s SBER@MISX -c XMOS --emission-rate 5m \
  --start-date 2025-01-09 --end-date 2025-03-31
```

- Минутный бандл может питать более медленный запуск: в Python API `load_bundle(..., frequency=..., aggregations=[...])` агрегирует бары до нужной частоты.
- Внутридневные бары поставщика размещаются на часах симуляции так, чтобы ни один бар не просочился в предыдущий.
- `time_rules` в `schedule_function` работают на любой внутридневной частоте.
- `data.history(frequency=...)` читает окно с интервалом, отличным от частоты запуска.

## Данные на момент публикации

Наборы данных, которые описывают прошлое с задержкой, — отчётность, фундаментальные показатели, раскрытия, — отбираются по дате, когда строка **стала публичной**, а не по периоду, который она описывает. Стратегия на баре `t` видит только то, что было опубликовано к `t`. Так же zipfinam обрабатывает MOEX AlgoPack: например, дневной итог виден стратегии только на следующей сессии.

<Warning>
  Движок не предназначен для стратегий, результат которых зависит от субсекундного времени исполнения, включая высокочастотную торговлю и арбитраж задержек. Подробнее — в разделе [«Ограничения»](/language/limitations/not-for-hft).
</Warning>
