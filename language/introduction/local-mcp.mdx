Чем бы вы ни писали стратегии — Claude Code, Codex, Cursor, — они могут вызывать Ziplime напрямую через MCP. Тогда цифры получает движок, а не модель.

## Установка и подключение

```bash
pip install "ziplime[mcp]" "zipfinam[all]"
```

С установленным zipfinam локальный сервер видит провайдер `finam`, календари Мосбиржи и адреса `algopack://`, поэтому агент может загружать данные по тикерам Мосбиржи. Не забудьте задать `GRPC_TOKEN` в окружении, из которого запускается сервер.

**Claude Code:**

```bash
claude mcp add ziplime -- ziplime mcp
```

**Claude Desktop, Cursor, Windsurf** и любой клиент, который запускает stdio-серверы:

```json
{ "mcpServers": { "ziplime": { "command": "ziplime", "args": ["mcp"] } } }
```

<Tip>
  Если вы ставили пакет в virtualenv, укажите в `command` полный путь к исполняемому файлу `ziplime` из него: десктопные приложения не видят `PATH` вашей оболочки. Переменные вроде `GRPC_TOKEN` передайте в блоке `env` конфигурации сервера.
</Tip>

## Инструменты

Локальный сервер предоставляет 14 инструментов:

| Этап | Инструменты |
| --- | --- |
| Данные | `list_data_providers`, `list_bundles`, `ingest_instruments`, `ingest_market_data` |
| Разработка | `get_strategy_language_reference`, `write_strategy`, `check_strategy_code`, `list_strategies`, `read_strategy` |
| Тестирование | `run_backtest`, `list_backtests`, `get_backtest`, `compare_backtests` |
| Реальная торговля | `describe_live_trading` — объясняет путь к реальной торговле; заявок не выставляет |

`check_strategy_code` — быстрая проверка по синтаксическому дереву, которая выполняется до того, как на код будет потрачен бэктест. Она блокирует запуск только при определённых ошибках (синтаксическая ошибка, нет `handle_data`, функция с неверной сигнатурой), а вероятные промахи — пропущенный `await`, `.iloc` на фрейме Polars — выдаёт как подсказки, которые запуск не блокируют.

Бэктесты, запущенные через MCP, по умолчанию исполняют заявки **на следующем баре**.

## Безопасность

- У сервера **нет инструмента для заявок**. Реальная торговля запускается из вашего терминала, а не через инструмент.
- Сервер **запускает код, который пишет агент**, на вашей машине и с вашими правами. Прежде чем подключать агента, прочитайте `SECURITY.md` в репозитории.

## Локальный сервер и платформа

На платформе Ziplime от Финама есть и размещённый сервер — `https://ziplime.finam.ru/mcp`, с данными Мосбиржи от Финама. Оба работают на одном движке, но по разным правилам для кода:

| | Локальный — `ziplime mcp` | Платформа — `ziplime.finam.ru/mcp` |
| --- | --- | --- |
| Установка | `pip install "ziplime[mcp]" "zipfinam[all]"` | не нужна |
| Учётная запись | не нужна (для данных Финама — токен Trade API) | учётная запись Ziplime от Финама |
| Код стратегии | обычный модуль Python: импорты, `before_trading_start`, `analyze`, класс конфигурации | песочница: без импортов, только `initialize` и `handle_data` |
| Данные | Finam Trade API, MOEX AlgoPack, Yahoo Finance, наборы Hugging Face, ваши CSV | данные Мосбиржи от Финама |

Каждый сервер сообщает агенту свои правила через `get_strategy_language_reference`, поэтому агент, подключённый к обоим, пишет для каждого правильный код.
