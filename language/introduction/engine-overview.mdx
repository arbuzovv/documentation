Ziplime — открытый движок бэктестинга на Python: [github.com/Limex-com/ziplime](https://github.com/Limex-com/ziplime). В этом разделе описан движок в том виде, в каком вы устанавливаете и запускаете его сами, — текущая версия **2.11.0**. Российский рынок к нему подключает открытая библиотека [zipfinam](https://github.com/arbuzovv/zipFinam): котировки и справочник инструментов из Finam Trade API, календари Мосбиржи и исполнение заявок на счёте в Финаме.

Ziplime вырос из форка **Zipline** — движка, на котором работала платформа Quantopian, — и сохранил его модель программирования: `initialize`, `handle_data`, `context`, `data`, `order_target_percent`. Большая часть движка с тех пор переписана: в слое данных Polars вместо pandas, asyncio на всех уровнях, Python 3.12+.

<Note>
  Платформа [ziplime.finam.ru](https://ziplime.finam.ru) запускает тот же движок в песочнице с более узким контрактом: без импортов, только `initialize` и `handle_data`, без класса конфигурации. В этом разделе описан открытый движок. На платформе следуйте правилам, которые дают её собственный редактор и MCP-сервер.
</Note>

## Строгий по умолчанию

Движок построен так, чтобы ловить ошибки, которые допускает стратегия, написанная вручную или ИИ. Упрощения, которые приукрашивают результат бэктеста, нужно включать явно:

- **Исполнение на следующем баре.** В CLI и локальном MCP-сервере заявка исполняется на баре после принятия решения. Исполнение на том же баре включается отдельным флагом.
- **Проверка векторных сигналов на заглядывание в будущее.** `compute_signals` пересчитывается на усечённой истории, и сигнал, который использовал будущие данные, останавливает запуск до первой заявки.
- **Данные на момент публикации.** Наборы данных вроде фундаментальных показателей или сделок инсайдеров отбираются по дате, когда строка стала публичной, а не по периоду, который она описывает.
- **Расходы применяются или останавливают запуск, но никогда не пропадают молча.** Модель расходов, которую нельзя применить, останавливает запуск с указанием её имени.
- **Ни один инструмент не выставляет заявки сам.** У локального MCP-сервера нет инструмента для заявок.

## Что входит в движок

| Область | Что вы получаете |
| --- | --- |
| Классы активов | Акции и фонды, фьючерсы, опционы, облигации — в одном портфеле, с одним денежным балансом и одним учётом |
| Симуляция | Событийный движок и векторное ядро; оба отчитываются через один учёт и одни модели расходов |
| Размер бара | Любая частота от минуты до дня (5 минут, 15, час…) |
| Данные | Finam Trade API и MOEX AlgoPack через zipfinam, Yahoo Finance, CSV, наборы данных на Hugging Face Hub, источники из расширений |
| Площадки | Каждый листинг живёт по часам своей площадки, поэтому один запуск может объединять рынки — например, `MISX` и `RTSX` |
| Запуск | Командная строка (`ziplime …`), Python API (`run_simulation`), локальный MCP-сервер для ИИ-агентов |
| Реальная торговля | Тот же файл стратегии торгует на счёте в Финаме через [Finam Trade API](https://api.finam.ru/) |

Денежные значения для рублёвых инструментов — например, акций Мосбиржи **SBER**, **GAZP** и **LKOH** — рассчитываются в рублях.
